Conceitos de Texto

A HTML5 trouxe muitas tags de texto. Por exemplo, podemos destacar um texto com marcação visual, usar negrito semântico para importância e itálico para ênfase.

Quando usamos uma abreviação, como HTML, ajudamos os leitores de tela. Se definirmos um termo, usamos Semântica, que significa dar significado ao código.

Uma citação em bloco:

"A semântica em HTML significa usar as tags apropriadas para o conteúdo correto."
E uma citação curta: Como disse o criador, isso é maravilhoso. A fonte desse trabalho é MDN Web Docs.
